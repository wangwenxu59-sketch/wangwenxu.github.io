共享文件打印站 —— 使用说明
=====================================

一、如何共享文件？
  1. 把文件（PDF / 图片 / 文本等）放入本仓库的 files/ 文件夹
  2. 提交并推送到 GitHub
  3. GitHub Actions 会自动更新文件列表，网站上立即显示

二、如何打印？
  1. 在网页上找到目标文件
  2. 点击「打印」按钮，选择打印机即可
  3. PDF 会直接调起打印；图片和文本会自动排版后打印

三、支持类型
  - PDF：在线预览 + 直接打印（最推荐，格式不会乱）
  - 图片：jpg / png / gif / webp / svg 预览打印
  - 文本：txt / md / csv / json 等预览打印
  - 其他格式：提供下载

本文件本身也可以作为打印测试页使用 —— 点击右侧「打印」按钮试试！
